# Road financing in Brazil, described

Descriptive statistics of road infrastructure financing in Brazil, 2002-2025, prepared for the thesis *Financing Channels and the Quality of Infrastructure Investment: Evidence from Brazil* (Arthur Cassemiro, Unicamp, Instituto de Economia). Document for the supervisor meeting of 22 October 2026.

- `index.html` (also `descriptive_statistics_road_financing.html`): the page, one self-contained file; it loads Chart.js and two Google fonts from the internet, everything else is embedded. Served by GitHub Pages at the repository's root.
- `metadata_descriptive_statistics.xlsx`: one sheet per chart or table with its data, plus `Index` (id, title, source, period, unit, coverage) and `Tests`.
- `presentation_script.md`: the presentation script.
- `dados/`: the 57 CSV tables behind the charts (one per figure, named by chart id), `index.csv`, `testes.csv` (reconciliation tests) and `spot_checks.csv` (random contracts traced from the source register to the chart row).
- `capa/`: the cover (PDF) and the photo embedded in the page.

Five parts: infrastructure general data; federative aspects of the states; the financing channels trajectories; contracts performance; conclusions (three answers). Every number comes from the thesis databases (state database of 14 states, federal project base, external credit and macro module); nothing is typed by hand; budget stages are never added; what cannot be measured is said, not filled.

The tables and the page are generated by two scripts kept with the thesis databases (`44_descritiva_orientadora_dados.py`, `45_descritiva_orientadora_html.py`); this repository holds the outputs only.
